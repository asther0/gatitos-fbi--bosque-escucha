# Landing Bosque Escucha

Sitio estático independiente del centro de comando.

- Producción: https://bosque-escucha-landing.vercel.app
- Centro de comando: https://bosque-escucha.vercel.app
- Proyecto Vercel: `bosque-escucha-landing`.
- Sin instalación de dependencias ni variables de entorno.

## Vista local

```sh
cd landing
python3 -m http.server 8080
```

El formulario de piloto descarga una propuesta de texto; no registra ni envía datos.
